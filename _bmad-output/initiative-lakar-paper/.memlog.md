- (direction) Fatmuh (2026-11-22): pemilik keputusan sekarang Fatmuh; Lakar dibuat setara paper.design: editor penuh, komponen dan token, ekspor/sinkron kode, dan pembanding kualitas agen (brief §Arahan pemilik)
- (decision) Sofia atas delegasi Fatmuh (2026-11-22): arah Paper menjadi inisiatif baru initiative-lakar-paper; initiative-lakar ditutup pada G0 + B, riwayat keputusan Adam utuh
- (decision) Sofia atas delegasi Fatmuh (2026-11-22): G1 vs pen.dev di-drop; gerbang kualitas baru membandingkan agen Lakar dengan agen di Paper memakai golden set dan rubrik versi baru; breakdown G1 lama dipakai ulang sebagai input (aturan LC, pemadatan skill, harness bench)
- (requirement) R1 (brief §Editor): pengguna mengedit desain langsung di canvas: pilih, multi-select, geser, ubah ukuran, edit teks inline, group, duplikat, hapus, align, undo/redo, shortcut, dan edit properti (fill, stroke, radius, efek, tipografi, auto-layout flex/grid) di panel properti; terbukti bila satu landing page lengkap dibuat dari kosong tanpa agen
- (requirement) R2 (brief §Agen di canvas): agen di harness membaca dan menulis dokumen yang sama lewat MCP, termasuk seleksi pengguna, dan perubahan manual maupun agen tampil live di kedua sisi; terbukti bila pengguna memilih frame, meminta varian responsif di harness, dan hasilnya muncul live di canvas
- (requirement) R3 (brief §Token dan tema): token warna, radius, spacing, container, breakpoint, font family, font weight, font size, line height, dan letter spacing dikelola di panel Theme, dipakai dan dilepas dari panel properti, dengan mode tema; terbukti bila mengubah satu token mengubah semua node pemakainya di canvas dan di ekspor kode
- (requirement) R4 (brief §Komponen): komponen dengan instance, override, props, dan slot; perubahan master menyebar ke instance; terbukti bila mengubah master memperbarui semua instance tanpa menimpa override
- (requirement) R5 (brief §Kode): frame diekspor ke React dengan Tailwind atau CSS idiomatik yang memakai token; token diimpor dari CSS variables codebase; terbukti bila komponen hasil ekspor dirender di browser sama dengan canvas (selisih piksel di bawah ambang yang ditetapkan)
- (requirement) R6 (brief §Editor paste): HTML dan SVG yang di-paste menjadi layer yang bisa diedit; terbukti bila potongan HTML dan SVG contoh menjadi layer dengan struktur dan gaya terjaga
- (requirement) R7 (brief §Editor vektor): pen tool dan edit path vektor dengan detail SVG terjaga; terbukti bila ikon SVG diimpor, diedit titiknya, lalu diekspor kembali tanpa kehilangan atribut
- (requirement) R8 (brief §Arahan pemilik, pembanding kualitas): agen Lakar setara atau lebih baik dari agen di Paper pada golden set versi baru, dengan pengukuran simetris; lulus bila >= 4/5 prompt setara atau lebih baik, >= 1 lebih baik, nol emoji, waktu <= 1,5x; terbukti bila bench/round-<n>.md memutuskannya dan Fatmuh mengonfirmasi
- (constraint) C1 (brief §Arahan pemilik): setara fitur dan alur kerja, bukan salinan; UI mengikuti design/lakar-ui.pen yang diperluas di Pencil; nama, API, aset, dan kode Paper tidak disalin
- (constraint) C2 (brief §Arahan pemilik): lokal satu pengguna tanpa akun untuk sekarang; akun, tim, berbagi, dan cloud menyusul di inisiatif berikutnya
- (constraint) C3 (initiative-lakar C1, C5): format dokumen milik Lakar dengan schemaVersion dan migrasi; tanpa Penpot, tanpa format .pen atau Paper
- (constraint) C4 (initiative-lakar C3): bila kualitas hasil desain bertukar dengan kecepatan membangun, kualitas menang
- (constraint) C5 (initiative-lakar C7, C8): rubrik dan kriteria golden tidak dibaca agen; waktu dan biaya kedua alat diukur sama, satu putaran semua prompt tanpa memilih run terbaik
- (constraint) C6 (AGENTS.md): aturan repo tetap berlaku: route dan tool lama dibekukan untuk bench, arah dependensi viewer, guard Origin route tulis /viewer/*
- (question) Model dokumen: tetap skema JSON Lakar yang diperluas, atau bergeser ke model HTML/CSS-native seperti Paper; menunggu bmad-architecture sebelum epic editor di-refine
- (question) Akses pembanding: Paper Desktop hanya macOS, MCP hosted butuh akun; bagaimana baseline Paper dijalankan dari mesin Windows/VPS; menunggu epic gerbang kualitas
- (question) Desain UI panel baru (properti yang bisa diedit, Theme, komponen, kode) belum ada di design/lakar-ui.pen; perlu diperluas di Pencil sebelum epic terkait dibangun
- (question) Golden set dan rubrik versi baru untuk pembanding Paper belum ada; siapa dan kapan disusun; menunggu epic gerbang kualitas
- (decision) Sofia (2026-11-22): paste dari Figma dan ekstensi Snapshot situs langsung di luar cakupan awal; HTML dan SVG paste di dalam (R6)
