# Lakar: typography

## Pasangan huruf

Nada brief → pasangan (font terpasang, brand menang): tegas = Bricolage Grotesque + Inter · hangat = DM Sans · teknis = Inter/Plus Jakarta Sans + mono angka · premium = Manrope, display besar bobot ringan. Display berat dan rapat, isi biasa dan lega; display tidak untuk label kecil.

## Skala

- ±5 ukuran, 2–3 bobot; lompatan antarperan ≥ 1,2× (mobile) / 1,25× (desktop); satu ukuran per jenis elemen.
- Paragraf ≥ 3 baris: line-height ≥ 1,4×. Tracking −0,01 sampai −0,02 em untuk ≥ 24; +0,05 sampai +0,08 em untuk kapital ≤ 14.
- Teks terang di latar gelap: line-height sedikit longgar, bobot naik satu tingkat. `numeric:'tabular'` untuk harga, jam, hitungan, kolom angka.

## Susunan

Judul dan paragraf tanpa kata yatim. Satu kata berwarna/tebal di headline maks sekali per halaman. Overline aksen maks 2 per halaman/layar, hanya bila membawa informasi. Maks 2 "·" per baris.
