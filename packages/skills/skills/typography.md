# Lakar: typography

## Pasangan huruf

- Pilih pasangan display + teks dari nada brief sebelum layout, di antara font terpasang (`core`): tegas/berani → Bricolage Grotesque display + Inter; hangat/ramah → DM Sans; presisi/teknis → Inter atau Plus Jakarta Sans + mono untuk angka; tenang/premium → Manrope dengan display besar berbobot ringan. Brand/font permintaan selalu menang.
- Kontras peran terlihat: display berat dan rapat, teks isi biasa dan lega. Display tidak dipakai untuk label kecil.

## Skala

- ±5 ukuran (maks 6 per board, `LC-27`) dan 2–3 bobot. Lompatan antarperan ≥ 1,2× (mobile) atau ≥ 1,25× (desktop). Satu ukuran per jenis elemen.
- Baris 45–75 karakter (`LC-28`): 16 px → lebar 520–640, 18 px → 580–700.
- Paragraf ≥ 3 baris: line-height ≥ 1,4× ukuran.
- Tracking −0,01 sampai −0,02 em untuk ≥ 24 px; +0,05 sampai +0,08 em untuk huruf kapital ≤ 14 px.
- Bobot < 400 hanya untuk ≥ 28 px (`LC-29`). Teks terang di latar gelap: line-height sedikit lebih longgar dan bobot naik satu tingkat.
- `numeric:'tabular'` untuk harga, jam, hitungan, kolom angka.

## Susunan

- Judul dan paragraf tidak berakhir satu kata sendirian. Satu kata berwarna/tebal di headline paling banyak sekali per halaman.
- Overline aksen maks 2 per halaman/layar, hanya bila membawa informasi (kategori, langkah). Maks 2 "·" per baris.
